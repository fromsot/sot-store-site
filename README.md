# SOT-Store-Site

SOT｜店舗Webサポートの、店舗Webサイト本体（テンプレート＋生成の仕組み）を管理するリポジトリです。
進捗管理用の `SOT-Store-Web` リポジトリとは別に、Webサイトのソースコードだけをここで管理します
（2026-09-06 決定、詳細は SOT-Store-Web/docs/decisions.md を参照）。

## 仕組み

「データとテンプレートを分離する方式」を採用しています。

- `template/` … 全店舗共通のデザイン（HTML・CSS）
- `data/` … 店舗ごとの情報（店名・住所・営業時間など）を1店舗1つのJSONファイルにまとめたもの
- `build.py` … `data/` の中身を `template/` に流し込んで、`dist/` に各店舗のサイトを生成するスクリプト
- `dist/` … 生成された、そのまま公開できる状態のサイト（店舗ごとにフォルダが分かれる）

外部のツール（npmパッケージなど）は使わず、Python標準ライブラリだけで動きます。
インストール作業なしで、そのまま `python3 build.py` を実行できます。

## 使い方

```
python3 build.py
```

を実行すると、`data/` の中にある店舗ごとに `dist/<店舗のslug>/index.html` が生成されます。
生成された `dist/<slug>/index.html` をブラウザで開けば、見た目を確認できます。

## 新しい店舗を追加する手順

1. `data/` フォルダの中に、新しいJSONファイルを1つ追加する（`data/sample-cafe.json` をコピーして書き換えるとやりやすい）
2. 写真があれば `images/<slug>/` フォルダを作って置く（無ければ「写真準備中」の表示になる）
3. `python3 build.py` を実行する
4. `dist/<slug>/` が公開用の中身になる（GitHubにpushすると、Cloudflare Pages側で自動的にサイトへ反映される想定）

## 店舗ごとに色を変えたい場合

`data/<店舗>.json` の中の `theme` の値（`primary_color` など）を変更すると、
テンプレートは共通のまま、店舗ごとに色味だけを変えられます。

## 公開方法

Cloudflare Pages と連携し、`dist/<店舗のslug>/` フォルダをそのまま公開する想定です
（1店舗＝1つのCloudflare Pagesプロジェクトとして、店舗ごとにサブドメインを発行する形を想定）。
具体的な連携手順は、実際に連携する際にあらためて記録します。
